# Platform foundations (agent "plat") - working notes

Written incrementally. Honest status at the bottom of this file ("Report") once finished.

## 1. In-repo E2E suite (e2e/)
- `make e2e-smoke`: backend + dashboard only, no models/GPU. Green on first run (signup UI, personas, webhook receiver + HMAC, guest link, all 14 core routes at 1440 and 390).
- `make e2e`: full run (replica + voice consent via fake mic fed with Kokoro speech, worker training, persona + knowledge, live conversation, video, all routes, guest conversation, webhooks).

## 2. DB migrations - done
- `backend/alembic.ini`, `backend/alembic/env.py`, baseline `0001_baseline.py` (autogenerated from all `models_*.py` + `db.py`), `app/migrate.py` (status/upgrade/stamp/check CLI, `schema_diff`, startup `warn_if_behind` called from `db.init_db`).
- Rule enforced by `tests/test_migrations.py`: alembic head must equal the SQLModel metadata. When another agent adds/changes a model, run `alembic revision --autogenerate`.
- db.py: `check_same_thread` only for sqlite URLs (`engine_kwargs`), `MIRAGE_AUTO_CREATE=0` skips create_all for production.
- Postgres: DDL compile test only. NOT run against a real Postgres.

## 3. Storage - done
`app/storage.py` (Local default = unchanged paths; S3 via optional boto3; presigned 307 redirect after signature check). Hooked into jobs.py (publish after replica/video, ensure_local before render), jobs_api file serving, consent audio, listening clip, data_deletion. Tested with fake client + moto.

## 4. Observability - done
`app/metrics.py` (installed from main.py): request ids, JSON logs, /metrics (token), /health/deep, worker heartbeat (touched in jobs.run_once). `app/admin.py` CLI.

## 5. Billing enforcement - done
billing.py new section + models_platform.py (BillingSettings, OverageCharge); wired into resources.py (create/end conversation, create video), convo_runtime.end_conversation_row, realtime.py + guest_api.py (allowance), jobs.process_video (charge at start, refund on error), monthly reset loop in main lifespan. Endpoints in routers/billing.py. Stripe/Razorpay providers untouched, still untested live. Overage is recorded + capped, NOT invoiced to a card.

## 6. Workspaces - done (backend only)
`app/workspaces.py`, `routers/workspaces_api.py`, `X-Workspace` header handled in `auth.current_account`. No UI.
