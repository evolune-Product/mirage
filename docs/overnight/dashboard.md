## Honest caveats

- **Voice-match score and consent audio rendering was tested with a verification row I inserted into my isolated SQLite DB**, because producing a real recorded consent needs a microphone plus the speaker model. The UI reads the real endpoints, but I did not observe a genuine scored consent.
- **Tool "test"**: the backend has no tool-test endpoint. The UI shows the exact payload VocalFace will POST and a browser-side "Send sample call". Browsers enforce CORS, so it typically reports "blocked" for endpoints that do not send CORS headers; that is not evidence the server cannot reach it. The VocalFace server-side call itself was seen in a conversation (tool log row with the 501 returned by my dummy endpoint).
- **Listening clip "upload" is by URL**: the API (`POST /v1/replicas/{id}/listening-clip {url}`) only accepts a URL, there is no file upload. The UI handles 404 "Not Found" as "unavailable on this server". I submitted the 58 s founder video through it and the server accepted it (720x404, 25 fps), the drawer then showed the clip metadata.
- Objective results show what the backend judge stored. In my live conversation the 1B model judged both objectives complete with generic evidence, which is a backend/model quality issue, not UI.
- The live conversation used the shared Ollama and the shared lip-sync service on :8100 (read-only use through the playground); the 1B voice model produced garbage when a tool was attached, again backend/model behaviour.
- Guest links shown on the Conversations page load once at page open (not live).
- Memory list shape from `GET /memories` was handled defensively (string or object).
- Bulk/translate videos were queued only; I did not run the worker on them, so per-video "ready" state for batches is unverified beyond the error state the worker produced for earlier fake probes.
- Analytics charts were verified with one real conversation plus empty states; multi-day series, 90-day density and the video charts were not exercised with rich data.
- No git commits or pushes were made by me; no external services were contacted.
