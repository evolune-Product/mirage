# 2-minute demo script

Setup (before recording): `./dev.sh`, Ollama running, headphones on (avoids speaker echo), a replica already trained, a persona with a short pricing document, browser at http://localhost:3000.

1. (0:00) Landing page: "Open-core conversational video AI." Scroll once to show the pipeline and latency bars (real numbers).
2. (0:15) Dashboard overview: the onboarding checklist shows the path.
3. (0:25) Replicas: show the consent step. Read the phrase aloud once. "Nothing trains without the person's yes; it's revocable and audit-logged."
4. (0:45) Personas: open Sales Rep, show the knowledge document.
5. (0:55) Conversations -> Start conversation -> Start. Ask: "What does the starter plan cost per month?" The face answers from the document.
6. (1:20) Interrupt it mid-sentence to show barge-in.
7. (1:30) Videos: generate a 10 s script, show the queued -> ready flow and the player.
8. (1:50) Billing + API keys page: "Everything here is an API call; here is the curl."
9. (2:00) Close: "Voice stack self-hosted at $0 per minute; GPU face when you need premium quality."

Do not claim: sub-second latency, Tavus-level realism, customers, or revenue.
